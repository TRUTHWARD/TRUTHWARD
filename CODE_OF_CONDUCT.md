# 社区行为准则 / Community Code of Conduct

TRUTHWARD 社区希望讨论、Issue、Pull Request、代码评审和其他项目空间保持专业、
友善、安全并以事实为基础。本准则适用于所有参与者，也适用于代表本项目参加的线上或
线下活动。

TRUTHWARD expects discussions, Issues, Pull Requests, reviews, and other project spaces
to remain professional, welcoming, safe, and evidence-based. This Code applies to every
participant and whenever someone represents the project in another public or private space.

## 我们鼓励的行为 / Expected behavior

- 尊重不同经验、背景、身份和观点；使用清晰、克制且聚焦问题的语言。
- 对代码、设计和证据提出具体意见，不攻击、贬低或揣测贡献者本人。
- 在指出问题时给出可复现信息，承认不确定性，并及时更正错误。
- 尊重隐私和安全边界；公开内容应先移除 Token、凭据、个人信息、客户数据和漏洞利用细节。
- 接受维护者为保护社区、许可证、安全和架构边界而作出的善意管理决定。
- Be respectful across differences in experience, background, identity, and viewpoint.
- Critique code, design, and evidence rather than people; provide reproducible context and
  correct mistakes openly.
- Protect privacy and security by removing credentials, personal or customer data, and
  exploit details from public content.

## 不可接受的行为 / Unacceptable behavior

- 骚扰、威胁、仇恨言论、歧视性表达、性化内容或不受欢迎的性关注。
- 人身攻击、侮辱、持续挑衅、恶意跟踪或在被要求停止后继续联系。
- 未经许可公开他人的私人信息，或发布真实 Token、凭据、客户数据和敏感运行记录。
- 明知不实仍伪造测试、审计、性能、安全或外部 Provider 证据。
- 垃圾信息、协同操纵、冒充他人，或以其他方式干扰社区正常协作。
- Harassment, threats, hate speech, discrimination, sexualized content, personal attacks,
  doxxing, impersonation, spam, coordinated manipulation, or deliberate disruption.
- Knowingly fabricating testing, audit, performance, security, or external-provider evidence.

## 执行 / Enforcement

维护者可以编辑或移除不符合本准则的评论、提交、代码、Issue 或其他内容，并可根据行为
的严重程度和持续性采取提醒、正式警告、临时限制或永久禁止参与。处理时应尽量保护报告者
和受影响人员的隐私，避免利益冲突，并对相似行为采用一致标准。

Maintainers may edit or remove content that violates this Code and may issue a correction,
formal warning, temporary restriction, or permanent ban according to severity and pattern.
They should protect the privacy of reporters and affected people, avoid conflicts of
interest, and apply comparable responses to comparable conduct.

## 报告问题 / Reporting concerns

对于 GitHub 上的具体内容，请优先使用该内容菜单中的私密举报功能，让仓库管理员或 GitHub
处理。不要为了举报行为问题而公开个人信息、私聊截图或客户数据；如存在即时人身危险，
请联系所在地的紧急服务。当前项目尚未公布独立的私密行为准则邮箱；在正式提供该渠道前，
请使用 GitHub 的举报与支持机制。

For conduct tied to GitHub content, use the private report option in that content's menu so
repository administrators or GitHub can review it. Do not publish personal information,
private-message screenshots, or customer data to make a conduct report. Contact local
emergency services for an immediate threat. The project does not currently publish a
separate private conduct mailbox; use GitHub reporting and support controls until one is
formally provided.

安全漏洞应按照 [SECURITY.md](SECURITY.md) 私密报告；只有当行为事件本身同时构成安全
漏洞时才使用漏洞报告渠道。一般使用、安装和缺陷问题请按 [SUPPORT.md](SUPPORT.md) 分流。

Report security vulnerabilities through [SECURITY.md](SECURITY.md); use that channel for a
conduct incident only when it is also a security vulnerability. Route general usage,
installation, and reproducible software issues according to [SUPPORT.md](SUPPORT.md).
